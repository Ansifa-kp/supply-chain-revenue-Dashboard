# 📊 AI-Driven Supply Chain & Revenue Dashboard

A comprehensive data analytics project that integrates **MySQL**, **Python**, and **Excel** to analyze supply chain metrics, optimize inventory levels, and identify revenue-generating opportunities.

---

## 🎯 Project Overview
In modern supply chain management, balancing stock levels with demand while maximizing profit margins is critical. This project processes transactional and inventory data to solve key operational challenges:
- **Inventory Optimization**: Identifying slow-moving inventory vs. high-demand items to prevent stockouts and overstocking.
- **Revenue & Pricing Trends**: Analyzing rental rates, unit prices, and revenue performance across categories.
- **Data Engineering Pipeline**: Cleaning raw database schemas using SQL queries (`project.sql`) for downstream analytics and reporting.

---

## 🛠️ Tech Stack & Tools
- **Database & Querying**: MySQL (aggregations, joins, data extraction)
- **Data Analytics**: Python (Pandas, NumPy)
- **Visualization & Reporting**: Microsoft Excel / Power BI
- **Version Control**: Git & GitHub
- **Environment**: Visual Studio Code (VS Code)
